# Laboratório ADVPL Protheus

Coleção de exemplos práticos de ADVPL para TOTVS Protheus — padrões reutilizáveis para cenários comuns de desenvolvimento no ERP.

> **Aviso Legal**: Todos os exemplos são educacionais. Nomes de tabelas fictícios, dados simulados e estruturas genéricas. Não derivado de código de produção de nenhum cliente específico.

## Exemplos

### Centro de Custo por Série
Atribuição dinâmica de centro de custo com base na série do documento — útil para operações multifilial.
`ADVPL` `Financeiro`

### Filtro Condicional em SX5
Filtro de opções da tabela SX5 com base em regras de negócio (estado, empresa, parâmetros).
`ADVPL` `Configuração`

### Auto Registro
Registro automático de dados em tabelas customizadas durante processos padrão.
`ADVPL` `Cadastro`

### Relatório Financeiro
Relatório financeiro estruturado utilizando TReport com agrupamentos e totalizadores.
`ADVPL` `Relatório`

## Tecnologias

`ADVPL` `TOTVS Protheus` `TReport` `SX5` `PE`
