# Protheus ADVPL Lab

Collection of practical ADVPL examples for TOTVS Protheus — reusable patterns for common ERP development scenarios.

> **Disclaimer**: All examples are educational. Fictional table names, mock data, and generic structures. Not derived from any specific client's production code.

## Examples

### Cost Center by Series
Dynamic cost center assignment based on document series — useful for multi-branch operations.
`ADVPL` `Financeiro`

### SX5 Conditional Filter
Filter SX5 table options based on business rules (state, company, parameters).
`ADVPL` `Configuração`

### Auto Register
Automatically register records in custom tables during standard processes.
`ADVPL` `Cadastro`

### Financial Report
Structured financial report using TReport with grouping and totals.
`ADVPL` `Relatório`

## Tech Stack

`ADVPL` `TOTVS Protheus` `TReport` `SX5` `PE`
